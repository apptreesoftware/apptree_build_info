# What's New in 2026.3.2

## What's new

- **Toolbar works at larger text sizes.** If you use a larger font size on your device, buttons that don't fit move into the "more" (⋮) menu instead of overlapping.
- **Search filters the map on the web.** Searching a work order list on the web now also filters the map pins and summaries.

---

## Fixes and improvements

- Number fields accept numbers only and are easier to edit.
- Opening a form while offline now shows an offline message instead of "Feature not found".
- Saving changes while offline is faster and no longer waits on the network.
- Tapping a picker quickly no longer opens it twice.
- Backing out of an "Add" screen no longer leaves an empty row on the work order.
- On the web, the camera now turns off when you close the barcode scanner.
- When a request can't be completed, the app now shows a clear message instead of a technical error code.
- General stability improvements and crash fixes.
